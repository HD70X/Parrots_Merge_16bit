# Parrots_16bit
A simple merge game.

Yes, this is a simple merge game; you can think of it as a template.

This template allows you to add any number of levels, any seasons, any mergeable items, and even any completion conditions. Yes, each of these can be accomplished by simply adding a Resource configuration file.

If you're willing to do some research, you can also add more complex judgments, more complex scenes, and so on. If you like.
