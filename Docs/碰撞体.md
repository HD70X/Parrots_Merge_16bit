### 1. 设计目标

- 在合成消除玩法中，投掷物需要长期堆叠、频繁碰撞、并在合成瞬间发生“删除与生成”。
- 目标是让物理表现：
    - **稳定**：尽量少出现随机弹飞、穿透、强烈抖动。
    - **可预测**：同类场景下结果相近，便于调参与关卡设计。
    - **可扩展**：后续加入新投掷物、障碍物、关卡变化时，不需要推翻碰撞与物理基线。

### 2. 统一原则（必须遵守）

1. **稳定性优先于形状精确度**
    - 碰撞体不需要 100% 贴合像素轮廓。
    - 优先保证堆叠、滑动与合成过程稳定。
2. **减少尖角与复杂接触点**
    - 尖角越多，越容易产生不可控力矩与分离冲量。
3. **合成生成必须有“物理安全策略”**
    - 合成瞬间是物理异常高发点，必须用统一规则软着陆。

### 3. 推荐节点结构（投掷物）

- 根节点：**RigidBody2D**
- 显示：Sprite2D
- 碰撞：CollisionShape2D（推荐）或 CollisionPolygon2D（谨慎）

### 4. 碰撞体形状策略

#### 4.1 默认方案：多个 CircleShape2D 组合

- **适用**：绝大多数投掷物（尤其像素风、轮廓复杂但追求稳定）。
- **优势**：
    - 接触点平滑，堆叠更稳。
    - 物理求解成本低。
    - 弹飞概率显著降低。
- **规范**：
    - 数量建议 **3–5 个圆**。
    - 用“主体大圆 + 局部小圆（头/尾/突出部分）”补形。
    - 允许略微超出视觉轮廓。

#### 4.2 谨慎方案：CollisionPolygon2D

- **适用**：少量特殊物体确实需要更贴合边界时。
- **风险**：尖角、凹陷导致弹飞与旋转更不可控。
- **规范**：
    - 顶点数量建议控制在 **10–20**。
    - 避免细长尖角与深凹。
    - 编辑器里看到的彩色块是三角剖分可视化，不影响运行，但复杂度越高风险越大。

### 5. RigidBody2D 调参基线（起始值建议）

> 说明：具体数值按手感微调，但应保持“低弹性 + 适度摩擦 + 合理阻尼”的方向。
> 
- Gravity Scale：默认 1
- Mass：默认 1（后续按反馈调）
- PhysicsMaterial：
    - Bounce：偏低（例如 0.0–0.2）
    - Friction：中等偏高（例如 0.4–0.8）
- Damp：
    - Linear Damp：适度提高，让物体更快稳定
    - Angular Damp：适度提高，避免疯狂旋转

**调参规则**：

- 反弹太强：先降 Bounce，再加 Linear Damp。
- 旋转过猛：提高 Angular Damp；必要时对极少数物体 Lock Rotation。
- 堆叠易滑落：提高 Friction。

### 6. 合成时的“物理安全策略”（必须）

#### 6.1 生成位置

- 禁止：简单取两物体中点作为唯一方案（易重叠）。
- 推荐：以“**更高者位置**”为基准，并 **向上偏移**少量距离，给落位空间。

#### 6.2 软着陆（至少满足其一，推荐同时使用 A+B）

- **A. 短暂禁用碰撞**：新物体生成后短时间不参与碰撞，待落位后启用。
- **B. 缩放 Tween**：新物体从较小比例增长到 1.0，减少瞬间挤压。
- **C. 轻微扰动（可选）**：动画结束时施加很小的冲量，增强手感但必须足够小。

#### 6.3 合成触发去抖

- 规则：同一对象在一次合成流程中只能参与一次合成。
- 目的：避免 body_entered 多次触发导致重复生成或状态错乱。

### 7. 障碍物（固定但可旋转）设计要点

- 目标：位置固定不坠落，但可被撞击后旋转，产生可玩反馈。
- 推荐：**PinJoint2D** 固定 RigidBody2D 到世界点。
- 备选：StaticBody2D + 程序旋转（恒定转速，无真实物理反馈）。

### 8. 验收标准（Acceptance Criteria）

1. 投掷物堆叠时不出现明显的随机弹飞。
2. 合成生成瞬间不造成大范围弹飞或穿透。
3. 同一触发条件下合成只发生一次，不重复生成。
4. 在预期最大物体数量下，物理更新不出现明显卡顿峰值。
