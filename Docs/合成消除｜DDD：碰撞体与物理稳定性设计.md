### 1. 目标与范围

- **目标**：在合成消除类玩法中，保证投掷物（RigidBody2D）在高频碰撞、堆叠、合成生成的情况下，仍能维持**稳定、可预测**的物理表现。
- **范围**：
    - 投掷物节点结构与碰撞体形状策略
    - RigidBody2D 关键参数的调参原则
    - 合成生成瞬间的“物理安全”规则（避免弹飞、穿透、剧烈抖动）
    - 障碍物（如摩天轮）固定与旋转的实现思路
- **不在范围**：
    - 具体脚本代码、函数实现细节
    - UI、关卡、存档等系统设计（后续 DDD 另文覆盖）

### 2. 设计原则（Design Principles）

1. **稳定性优先于形状精确度**
    - 视觉轮廓可以“不完全贴合”，但物理碰撞必须稳定。
2. **减少尖角与复杂接触点**
    - 尖角越多，力矩与分离冲量越不可控，越容易弹飞。
3. **可调参、可复用、可扩展**
    - 每个投掷物在统一基线规则下运行，仅通过少量参数实现差异。
4. **合成生成要“软着陆”**
    - 合成瞬间是物理异常高发点，必须有明确的缓冲策略。

### 3. 约束与问题定义

#### 3.1 典型问题

- **弹飞**：不规则碰撞体（尤其多边形）在堆叠与挤压时产生不可控反弹。
- **剧烈旋转**：碰撞点落在尖角或边缘时产生大力矩。
- **穿透与纠偏冲量过大**：复杂形状更易出现轻微穿透，物理引擎分离时冲量过大。
- **合成后重叠**：新物体生成位置不当，导致与周围物体重叠，继而弹飞或卡住。

#### 3.2 性能约束（与碰撞体选择直接相关）

- 接触对数量随物体数量增长迅速。
- 复杂碰撞体会显著增加碰撞求解成本。

### 4. 场景与节点结构规范

#### 4.1 投掷物场景（Throwable）推荐结构

- **根节点**：RigidBody2D
- **显示节点**：Sprite2D
- **碰撞节点**：若干 CollisionShape2D（推荐）或 CollisionPolygon2D（谨慎使用）

#### 4.2 结构选择理由

- 物理体作为根节点，保证位置/旋转/速度等由物理系统统一驱动。
- UI 专用节点（如 TextureRect）不用于世界物体显示。

### 5. 碰撞体形状策略

#### 5.1 不规则多边形（CollisionPolygon2D）

- **适用场景**：极少数需要精确边界的特殊物体。
- **风险**：
    - 尖角造成更大力矩与弹飞概率
    - 编辑器中看到的彩色块是三角剖分可视化，不影响运行，但侧面反映了形状复杂度
- **约束规则**：
    - 顶点数量建议控制在 **10–20** 个以内
    - 避免细长尖角、凹陷过深的轮廓

#### 5.2 多圆组合（多个 CircleShape2D）——默认推荐

- **适用场景**：大多数投掷物（尤其像素风角色、轮廓复杂但追求稳定的物体）
- **优势**：
    - 接触点平滑，分离冲量更可控
    - 滚动/堆叠稳定
    - 求解成本更低
- **规范建议**：
    - 以“主体大圆 + 局部小圆（头/尾/突出部位）”组合
    - **数量建议 3–5 个**，避免过多
    - 允许略微超出视觉轮廓，以换取稳定

### 6. RigidBody2D 关键参数基线（Tuning Baseline）

> 目标：把“异常弹飞”与“过度滑动/抖动”的概率压到可接受区间，并保留可玩性。
> 

#### 6.1 基线参数（建议从此起步）

- Gravity Scale：默认 1（除非需要特殊浮力感）
- Mass：默认 1（后续按手感微调）
- PhysicsMaterial（材质覆盖）：
    - **Bounce**：偏低（例如 0.0–0.2）
    - **Friction**：中等偏高（例如 0.4–0.8）
- 阻尼（Damp）：
    - Linear Damp：适度提高以更快稳定
    - Angular Damp：适度提高以限制疯狂旋转

#### 6.2 参数调整原则

- 想减少弹跳：优先降低 Bounce，其次提高 Linear Damp。
- 想减少旋转：提高 Angular Damp；必要时对特定物体 Lock Rotation（但会损失“物理乐趣”）。
- 想让堆叠更稳：提高 Friction，避免“滑坡式连锁坍塌”。

### 7. 合成生成的物理安全规则（必须）

合成时建议遵循以下规则，以避免新物体引起连锁异常：

#### 7.1 生成位置规则

- 默认使用两物体的“中点”容易导致重叠。
- 推荐策略：选择**更高的那个物体**的位置作为基准，并额外 **向上偏移**一小段距离。

#### 7.2 软着陆规则（至少满足其一）

- **规则 A：短暂禁用碰撞**
    - 新物体生成后的短时间内不参与碰撞，待缩放/落位后再启用。
- **规则 B：缩放 Tween（从小到大）**
    - 新物体从较小尺度增长到 1.0，减少瞬间占据空间造成的挤压。
- **规则 C：轻微扰动（可选）**
    - 在动画结束时施加很小的冲量，让物体“落下”更自然。
    - 扰动必须足够小，以免再次引发弹飞。

#### 7.3 合成触发去抖（推荐）

- 同一对物体在接触回调中可能多次触发，需要明确“只合成一次”的规则：
    - 使用双方状态标记（例如 is_merging）
    - 或通过唯一 ID 比较确保只有一方执行合成

### 8. 固定但可旋转障碍物（以摩天轮为例）

#### 8.1 目标

- 位置固定不下落
- 能被投掷物撞击带动旋转（产生可玩反馈）

#### 8.2 推荐方案：PinJoint2D

- 轮子使用 RigidBody2D，Gravity Scale 设为 0
- 用 PinJoint2D 把轮子固定在世界某一点
- 通过调节 Angular Damp 控制停转速度

#### 8.3 备选方案：StaticBody2D + 程序旋转

- 适合需要“恒定转速”且不追求真实物理反馈的障碍物

### 9. 验收标准（Acceptance Criteria）

1. **稳定性**：投掷物在堆叠状态下不出现明显的随机弹飞。
2. **可预测性**：相同输入与相似初始状态下，物理结果大致一致（不要求完全确定）。
3. **合成安全**：合成生成的新物体不会在出现瞬间造成大范围弹飞或穿透。
4. **性能**：在预期最大同时物体数下，帧率与物理步进稳定，无明显卡顿峰值。
